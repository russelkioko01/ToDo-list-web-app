
# ✅ To-Do List Web App

## 📌 About the Project
The To-Do List Web App is a simple and interactive application designed to help users organize their daily activities, manage tasks, and keep track of their progress.

This project demonstrates my practical skills in web development, user interface design, and JavaScript programming.

## ✨ Features
- ➕ Add new tasks.
- ✅ Mark tasks as completed.
- 🗑️ Delete tasks when they are no longer needed.
- 📋 View and manage your task list.
- 📱 Simple and user-friendly interface.

## 🛠️ Technologies Used
- **HTML5** – Structures the application.
- **CSS3** – Styles the interface and improves the user experience.
- **JavaScript** – Handles task creation, completion, and deletion.

## 🚀 Getting Started

### Prerequisites
A modern web browser such as Google Chrome, Firefox, or Microsoft Edge.

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/russelkioko01/todo-list-web-app.git
   ```
2. Navigate to the project folder:
   ```bash
   cd todo-list-web-app
   ```
3. Open `index.html` in your browser.
